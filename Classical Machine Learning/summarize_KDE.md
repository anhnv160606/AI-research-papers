# What result did the Author try to reach?
In this paper, the Author wanted to create a probability function that estimates the distribution of population with some samples.

# What were the key elements of the approach?
the **kernel** term in **kernel density estimation** is the mathematical function used to smooth out individual data points into a continuous probability density curve.
We apply kernel for every available sample then take the average of all kernel and we have an estimation for distribution of population. The parameters in this function are type of kernal (gauss, tofat, linear,..) and the **bandwidth** - a parameter for adjusting the smooth level of distribution.

When I only have a limited amount of data but I want to estimate the distribution of population. I will consider this approach.
